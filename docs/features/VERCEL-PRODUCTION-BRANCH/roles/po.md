# VERCEL-PRODUCTION-BRANCH — PO Path

**Applicable Policy IDs:** DOC-005, RELEASE-002, SDLC-001

## Inputs and preconditions

- Preview deployment dari branch `main` tersedia dan dapat diakses.
- QA telah memberikan sign-off kualitas pada fitur-fitur di `main`.

## Permitted actions and decisions

- Memverifikasi fungsionalitas dan acceptance criteria produk di lingkungan Preview.
- Mengajukan atau membuka Pull Request dari `main` ke `production`.
- Memberikan keputusan formal persetujuan rilis ke Production kepada Owner.
- PO dilarang melakukan merge langsung ke branch `production`.

## Outputs and handoff

- Rekomendasi rilis dan daftar cakupan fitur diserahkan ke Owner untuk eksekusi rilis Production.
