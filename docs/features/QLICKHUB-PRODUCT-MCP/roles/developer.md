# QLICKHUB-PRODUCT-MCP — Developer Path

**Applicable Policy IDs:** DOC-005, AUTH-002, DOMAIN-002

Developer menerima Subtask normal dari Feature yang telah dipublish; alur delivery mengikuti
[Workflow](../../../2_WORKFLOW_AND_ROLES.md). Dev tidak boleh publish grooming melalui MCP v1,
termasuk saat memiliki delegasi pembuatan parent Task. Tool update kerja agent Dev adalah scope
lanjutan dan belum dirancang di Feature ini. Baca [authorization](../authorization.md).
