# FEATURE-REFERENCES-MEDIA — Product Owner Path

**Applicable Policy IDs:** DOC-005, AUTH-001, AUTH-002, DATA-001

## Inputs and preconditions

- Akun terautentikasi dengan peran `po` pada Workspace aktif.
- Feature berada pada tahap PRD dan sedang disiapkan spesifikasinya bersama Product Brief.

## Permitted actions and decisions

- Menambahkan seluruh tautan referensi (Figma, PRD eksternal, spreadsheet riset, video Loom/YouTube).
- Mengunggah gambar desain atau mockup alur kerja ke dalam galeri media dengan kompresi browser otomatis.
- Mengatur urutan tautan (_reorder_) agar tautan utama (misal: Desain Figma Utama) berada paling atas.
- Mengubah (_edit_) dan menghapus (_delete_) tautan atau gambar yang salah.
- Mengklik tautan (_direct redirect_) untuk memverifikasi bahwa URL eksternal valid dan dapat dibuka.

## Outputs and handoff

- Bagian "Referensi & Media" lengkap dengan tautan aktif dan galeri visual.
- Notifikasi / handoff ke Developer dan QA untuk memulai implementasi dan penyusunan Test Case berdasarkan referensi tersebut.
