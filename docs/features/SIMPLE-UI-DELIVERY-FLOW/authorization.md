# SIMPLE-UI-DELIVERY-FLOW — Authorization Matrix

**Applicable Policy IDs:** DOC-005, AUTH-001, AUTH-002, AI-013, RELEASE-001, RELEASE-002

Feature ini tidak memperluas hak peran yang ada. Aksi baru memakai policy yang sudah ada di
`apps/api/src/policies/` atau policy baru dengan pola yang sama. Semua baris wajib punya test izin dan
test tolak (403) di integration test.

| Action                                            | Owner / Admin                 | PO                            | Developer                    | QA                           | Backend enforcement and evidence                                                                                                   |
| ------------------------------------------------- | ----------------------------- | ----------------------------- | ---------------------------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Baca detail Feature, riwayat serah-terima, tahap  | Sesuai membership             | Sesuai membership             | Sesuai membership/assignment | Sesuai membership/assignment | `assertCanAccessTask` (`taskPolicy.ts`); E3 baca + 403 non-anggota                                                                 |
| Buat Plan, jawab pertanyaan AI, ubah draft, Apply | Ya                            | Ya                            | Tidak                        | Tidak                        | `assertCanCreateTask` (planner, sama dengan jalur AI sekarang) + policy baru `featurePlanPolicy`; E3 izin PO + 403 Dev/QA (AC-5.5) |
| Komentar dan balasan serah-terima                 | Sesuai akses task             | Sesuai akses task             | Sesuai akses task            | Sesuai akses task            | Policy komentar yang ada; `handoffKind` hanya label, tidak memberi hak; E3                                                         |
| Kirim ke QA (status subtask)                      | Sesuai aturan status yang ada | Sesuai aturan status yang ada | Assignee subtask             | Tidak                        | `assertCanMutateTask` dan transisi status yang ada; E3                                                                             |
| Buat/ubah Test Case, tandai smoke                 | Tidak                         | Tidak                         | Tidak                        | Ya                           | `assertCanCreateTestCase`, `assertCanUpdateTestCase` (`testManagementPolicy.ts`); E3 403 non-QA                                    |
| Jalankan run, simpan hasil, tambah bukti          | Tidak                         | Tidak                         | Tidak                        | Ya                           | `assertCanExecuteTestRun`, `assertCanAddTestResultEvidence`; E3 403 non-QA (AC-3.6)                                                |
| Minta perbaikan / buat bug dari hasil gagal       | Bug: Ya                       | Tidak                         | Tidak                        | Ya                           | `assertCanCreateBug` (`bugPolicy.ts`: Owner, Admin, QA); E3                                                                        |
| Catat laporan user sebagai bug Production         | Ya                            | Tidak                         | Tidak                        | Ya                           | `assertCanCreateBug`; `source` dan `releaseId` tidak memberi hak tambahan; E3                                                      |
| Sign-off QA                                       | Tidak                         | Tidak                         | Tidak                        | QA executor                  | `assertCanCreateQaSignOff` (`releaseDecisionPolicy.ts`); tidak berubah                                                             |
| Keputusan rilis                                   | Ya                            | Ya                            | Tidak                        | Tidak                        | `assertCanCreateReleaseDecision`; tidak berubah                                                                                    |
| Catat rilis (PR, commit, deploy ID)               | Ya                            | Ya                            | Tidak                        | Tidak                        | Policy baru `releasePolicy` mengikuti peran keputusan rilis; E3 izin + 403                                                         |
| Cek teknis dan smoke Production                   | Tidak                         | Tidak                         | Tidak                        | Ya                           | Policy baru `releasePolicy` + `assertCanExecuteTestRun` untuk smoke run; E3                                                        |
| Penerimaan user                                   | Ya                            | Ya                            | Tidak                        | Tidak                        | Policy baru `releasePolicy`; E3                                                                                                    |
| Tutup rilis                                       | Ya                            | Ya                            | Tidak                        | Tidak                        | Policy baru `releasePolicy` + validasi syarat tutup di service (AC-8.2); E3 izin, 403, dan 409 bila syarat belum terpenuhi         |
| Baca Tugas Saya                                   | Antrean per aktor             | Antrean per aktor             | Antrean per aktor            | Antrean per aktor            | Policy antrean yang ada (`workQueueService`); item "menunggu orang lain" hanya untuk pekerjaan yang terkait aktor; E3 per peran    |

UI visibility is not authorization. Tombol yang disembunyikan di UI tetap ditolak di backend bila
dipanggil langsung; setiap slice mencatat test izin dan test tolak di [testing.md](testing.md).
