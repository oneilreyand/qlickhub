## 1. Temuan dari kode

| Temuan                                                                                                                                                                                                                                                                |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `task_comments` belum punya penanda serah-terima. Halaman kerja QA saat ini menebak pesan Developer dari komentar pengirim yang dibuat dekat waktu kirim (`HANDOFF_LEAD_MS` di `QaSubtaskWorkSection.tsx`); tebakan itu tidak dapat dipakai antrean.                  |
| Item antrean (`WorkQueueItemSchema`) hanya punya `title` dan `reason`. Untuk `changes_requested`, alasan diambil dari `reviewNotes` subtask; untuk kartu "siap diuji" alasan hanya hitungan subtask. Tidak ada nama pengirim atau pesan terakhir.                     |
| Balasan komentar sudah didukung (`parentCommentId`) dan memicu notifikasi diskusi ke pembuat/penugas/yang disebut/penulis komentar induk (`taskDiscussionService`, Trigger 3). Jadi balasan ke komentar pengirim sudah memberi notifikasi tanpa kode notifikasi baru. |
| `authorization.md` sudah menetapkan: `handoffKind` hanya label, tidak memberi hak; akses mengikuti policy komentar yang ada.                                                                                                                                          |
