## 3. Tambahan: koreksi Requirement manual di pratinjau

Atas arahan Owner ("ingin ada update manual untuk mengubah yang diperlukan"; lingkup: hanya Requirement, sheet asli tidak diubah):

- `POST /workspaces/:ws/test-cases/import/row-requirement {importSessionId, requirementCode, sourceRowNumbers[], qaSubtaskId?}` mengubah baris staging milik sesi impor pengguna itu. Kode baru divalidasi sama seperti pratinjau (ada, aktif, tertaut ke Feature subtask QA); alasan penolakan berawalan "Requirement" dihapus, alasan lain tetap.
- Wizard: baris yang ditolak karena Requirement punya dropdown berisi Requirement sah Feature ini; ada aksi "Terapkan ke N baris" untuk menggantinya sekaligus. Hitungan baris valid/tidak valid ikut diperbarui.
- Perubahan hanya berlaku untuk sesi impor ini; mengambil ulang dari link membaca ulang sheet dan membatalkan koreksi.
- Di luar scope: mengedit judul/prioritas/langkah di pratinjau, menulis balik ke Google Sheets.
