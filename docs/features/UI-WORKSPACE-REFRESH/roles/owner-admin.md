# UI-WORKSPACE-REFRESH — Owner / Admin Path

**Applicable Policy IDs:** AUTH-001, AUTH-002, UI-001, DOC-005

## Inputs and preconditions

Active Workspace membership and access to the existing route; no elevated UI permission is introduced.

## Permitted actions and decisions

Read the unified workspace, choose Light/Dark, and use existing Owner/Admin actions in their existing
policy scope. This Feature does not grant release, status, or member-management actions.

## Outputs and handoff

Owner/Admin receives the same canonical Feature context and existing backend-derived signals.
