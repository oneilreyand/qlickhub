# Verification Reports

**Status:** Evidence index
**Scope:** Observed commands, validation results, handoffs, releases, and known gaps.

A report is evidence of what was observed at a point in time. It never creates or overrides product
policy; use the Product Knowledge Map and canonical SSoT documents for current rules. New reports
use [the report template](../../AGENT_REPORT_TEMPLATE.md). Older reports may predate the Work
Assurance fields and are retained as historical evidence, not silently upgraded evidence.

When relying on a report, confirm its date, environment, baseline, validation scope, and unresolved
gaps. For current work, the active [TODO](../../TODO.md) is the authoritative priority/status view.
